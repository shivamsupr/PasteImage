PasteImage
==========

Thanks for installing PasteImage.

It needs `pngpaste` (macOS only):

    brew install pngpaste

Then copy an image and run "PasteImage: Paste Image from Clipboard"
from the command palette. Key bindings are optional. Suggestions are in:
Preferences > Package Settings > PasteImage > Key Bindings

Settings: Preferences > Package Settings > PasteImage > Settings
